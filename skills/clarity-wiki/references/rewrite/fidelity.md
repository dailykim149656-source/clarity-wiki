# 윤문: Fidelity (의미와 사실 보존 검사)

**언제**: 수치, 인용, 법률, 시험 규정, 전문 기술, 채용 이력, 업무 판단이 포함된 문서의 최종 윤문 검사.

## 감사 체크

1. 원본과 윤문본의 숫자, 단위, 기간, 날짜, 비율, 금액, 변수, 코드, 이름을 대조한다.
2. 부정어, 조건절, 예외, 전제, 가능성과 확실성을 유지했는지 확인한다.
3. `가능성`, `추정`, `미확인`이 윤문 후 `확정`이나 `원인`으로 바뀌지 않았는지 검사한다.
4. 직접 인용을 수정하지 않는다. 인용이 부정확하다고 생각되면 원문 자료 확인이 필요하다고 표시한다.
5. 중요한 세부 사실이 삭제되거나 새로 들어가지 않았는지 문단별 대조한다.
6. 고유한 작성자의 말투나 의도된 유머가 평균적 문체로 평준화되지 않았는지 확인한다.
7. 지나친 수정으로 결론의 강도, 독자, 장르가 바뀌면 해당 문장만 원복한다.

## 상태 표기

- `보존`: 사실과 조건 동일, 표현만 개선됨.
- `검토 필요`: 원문 자체가 모호하거나 비교 자료가 없음.
- `원복`: 뜻, 강도, 인용, 기술적 의미를 바꿔 되돌림.

의미 보존은 자동 점수 하나로 입증되지 않는다. 수치 일치 검사는 결정론적 도구를 사용해도 좋지만 인과/조건은 원문 대조가 필요하다.

## 출력

- 사용자가 결과만 원하면 보존된 최종본만 출력한다.
- 위험도가 높은 문서라면 `수정본` 아래 `직접 확인되지 않은 부분`을 1~3줄로 기록한다.
