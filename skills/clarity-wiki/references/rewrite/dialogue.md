# 윤문: Dialogue (대사, 대화, 구어체)

**언제**: 게임, 웹툰, 소설, 캐릭터 챗봇, 상담/응대 메시지, 실제 대화 문구.

말매치의 평가 축을 참고하되 원문 복제나 도구 실행 없이 **이 장면에 필요한 축만** 검수한다.

## 먼저 잠금

- 인물의 캐릭터/나이/관계, 장소, 시대, 직전 사건, 감정 상태, 의도한 농담이나 어색함.
- 사용자가 명시한 어체(반말, 해요체, 하십시오체, 반존대)와 대사 분량.

## 검수 축

| 축 | 질문 |
|---|---|
| 자연스러움 | 실제 한국어 구어로 말할 수 있는 길이와 조사/호응인가? |
| 캐릭터 일치 | 이 사람이 이 단어와 어미를 고를 이유가 있는가? |
| 관계 적합성 | 친밀도, 권력 거리, 예의 수준을 넘어가지 않는가? |
| 어체 일관성 | 존대 전환의 이유가 장면 안에 보이는가? |
| 유머 타이밍 | 웃기려는 문장 때문에 감정이나 사건이 끊기지 않는가? |
| 작위성 위험 | 캐릭터가 스스로 자기 감정을 장황하게 설명하지 않는가? |
| 시대 및 장르 | 배경에 없는 유행어, 플랫폼 어휘를 추가하지 않았는가? |
| 매체 적합성 | 말풍선/선택지/화면에 들어갈 정보량인가? |

## 수행

1. 이 장면에서 중요한 축 최대 3개만 선택한다.
2. 어색한 대사만 골라 `최소 수정` 한 가지를 낸다.
3. 의도적으로 낯선 대사나 캐릭터 개성은 억지로 표준화하지 않는다.
4. 논리적 오류와 말투 오류를 분리한다. 사실을 바꾸는 수정은 별도 승인 대상으로 표시한다.

## 출력

`문제 대사 → 제안 대사 → 수정 이유(1줄)` 형식 또는 사용자가 요청한 최종 대사만 출력한다.
