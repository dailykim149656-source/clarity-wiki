# 윤문: Quick (빠른 한국어 문장 다듬기)

**언제**: 1~몇 문단, SNS 글, 안내문, 짧은 메일, 자연스러운 문장 편집. 글쓴이의 의도와 장르가 분명할 때.

## 절차

1. 글의 목적, 독자, 어투를 한 문장으로 파악한다. 샘플이 있으면 그대로 따른다.
2. 사실과 고유명사, 숫자, 날짜, 단위, 직접 인용, 기술 용어는 잠근다.
3. 실제로 어색한 구절만 찾는다. 예: 불필요한 번역투, 이중 피동, 동일한 종결 반복, 추상명사 과다, 의도 없는 3단 병렬, 제목과 이모지 남발, 의미 없는 결론 문장. 근거가 의심되는 주장이나 과장은 본문에서 삭제·약화하지 않고 별도 검토 의견으로 표시한다.
4. **문제 구간만** 수정한다. 사람의 말투, 유머, 뉘앙스, 일부러 넣은 곁말은 보존한다.
5. 원문과 수정문을 비교해 사실 추가, 주장 강도 변화, 빠진 조건을 검사한다.

## 편집 원칙

- "AI 티"라는 스타일 신호만으로 작성 주체를 판정하지 않는다.
- `A가 아니라 B다`, `단순히 ~를 넘어`, `이를 통해`, `주목할 만하다`, `본질적으로` 같은 상투 구문은 **실제로 불필요할 때만** 손본다. 모든 표현을 기계적으로 삭제하지 않는다.
- 핵심 정보를 첫 문장에 둔다. 읽는 사람이 문장을 다시 읽지 않아도 이해할 수 있도록 구체적인 주어와 동사를 쓴다.
- 목표 분량이 없으면 원문의 밀도를 유지한다. 내용 추가가 필요하면 원문 근거 안에서만 풀어쓴다.
- 글이 이미 자연스러우면 거의 건드리지 않는다.

## 출력

기본: **윤문본만 먼저**. 필요할 때 수정 이유 1~3개. 다른 주장과 톤으로 바뀐 문장이 있다면 되돌리고 사용자의 판단을 기다린다.
