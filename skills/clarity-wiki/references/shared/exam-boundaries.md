# 환경 프로필: SK하이닉스 Cofa Probe 2차

프로필 버전 0.3.0 · 정리 기준일 2026-10-26 (Asia/Seoul).

해당 시험 환경이 명시된 경우에만 적용한다. 더 최신 공식 공지와 실제 응시 화면 지시가 우선한다. 이 요약은 원문 규정이나 설치 승인서가 아니다. 근거는 제공된 공식 안내의 아래 위치이며 PDF 원본과 실제 시험 자료는 공개 패키지에 포함하지 않는다.

## 공식 안내에서 확인한 조건

| 조건 요약 | 원문 위치 |
|---|---|
| 일반적으로 공개된 Skill·GitHub 저장소·MCP·Plugin을 과제 용도로 사용하고 Clone·다운로드할 수 있음 | 상세 가이드 p.5 §9; 필수확인 브리프 p.1 |
| 제공 MCP 탭에서 서버 JSON을 저장하면 Codex 설정에 반영됨 | 상세 가이드 p.3 §5 |
| 문제·파일·결과물 외부 전송·공유, Git Push, 개인 PC 파일 업로드 금지 | 상세 가이드 p.5 §9 |
| 제공된 Codex 사용. 외부 LLM·개인 API 키·개인 유료 구독·별도 모델 연결 금지, Astra 사용 제한 | 상세 가이드 p.5 §9; 필수확인 브리프 p.1 |
| Computer Use 자동 조작은 전 단계 금지 | 필수확인 브리프 p.1 |
| 작업 기록·테스트 결과 수집 및 토큰 사용량 추적 | 상세 가이드 p.1, p.5 §9 |
| 제출 문서는 AI와 작성할 수 있으나 제출 후 서술형은 AI 없이 본인이 작성 | 상세 가이드 p.3 §6; 필수확인 브리프 p.1 |

공개 도구 허용과 개별 도구·설치 방식의 승인은 같지 않다. 작성자 자신이 사전 공개한 범용 저장소의 인정 여부와 제공 환경의 실제 실행 가능성은 별도 확인 대상이다. 네트워크 없는 로컬 검사 스크립트나 MCP가 일괄 금지된다고 해석하지 않는다.

## 이 패키지의 운영 선택

아래는 공식 조항을 확장한 금지 목록이 아니라, 이 패키지를 운용하는 방식이다.

- 검사 도구는 로컬 파일만 읽고 네트워크·외부 LLM·API 키·텔레메트리를 사용하지 않는다. 모델·계정·보안 설정을 바꾸거나 차단을 우회하지 않는다.
- 메신저·브라우저·Computer Use 자동 조작과 자동 제출을 하지 않는다. 필요한 화면 확인과 메시지 발송·제출은 응시자가 직접 한다. 업무 판단 질문과 사용법 문의는 구분해 초안만 제공한다.
- 허용된 터미널에서 필요한 테스트와 로컬 검사를 실행한다. MCP 설정은 제공된 허용 경로만 쓰며 실패하면 CLI 또는 수동 대조로 전환한다.
- 내장 Browser 확인이 필요하면 응시자가 직접 처리한다. 이 문서는 브라우저 자동화 사용 권한을 부여하지 않는다.
- **AI 금지 후속 서술형 단계에 진입하면 Skill·CLI/MCP를 통한 AI 지원을 중단한다.** 해당 답안을 작성·첨삭하거나 우회 방법을 제공하지 않는다.

시험 전 공개 배포물에는 개인 프로필·실제 과제·시험 데이터·규정 PDF·작업 로그를 넣지 않는다. 규정 문의는 초안을 작성할 수 있으나 자동 발송하지 않는다. 호스트 인식과 설치는 허용된 사전 체험에서 확인하며 이 패키지가 시험 환경에서 인증됐다고 주장하지 않는다.
