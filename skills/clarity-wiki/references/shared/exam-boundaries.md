# 환경 프로필: SK하이닉스 Cofa Probe 2차 원회차 기록

패키지 버전 0.4.0 · 안내 갱신일 2026-10-31 (Asia/Seoul).

아래 규정·일정은 2026-10-31 원회차를 위해 제공받은 자료의 기록이다. 재응시 날짜·시간·사전 체험·도구 허용 조건은 새 공식 안내로 확인하며 이 기록을 그대로 적용하지 않는다. 사용자는 원회차에서 CLI 검증만 수행할 수 있었다고 보고했다. 현재 패키지는 Skill과 CLI만 제공한다.

해당 시험 환경이 명시된 경우에만 적용한다. 근거는 기존 공식 가이드 3종, 사용자가 2026-10-30에 제공한 크래프톤 Cofa 운영팀 메일 본문, 시험 시작 전 안내 화면이다. 메일 발송일은 제공 본문에 없어 단정하지 않는다. **메일과 기존 가이드가 다르면 메일을 우선**하고, 메일에 없는 사항은 기존 가이드를 따른다. 10월 31일 09:40 추가 공지와 이후 공식 안내도 확인한다. 메일 뒤에 붙은 해설은 공식 조항의 근거로 사용하지 않는다. 개인별 접속 링크·메일 원문·PDF 원본·실제 시험 자료는 공개 패키지에 포함하지 않는다.

## 원회차 일정과 체험 순서

- **2026-10-31(토) 09:40까지 접속·사전 준비 완료**, 같은 시각 이메일로 오는 추가 공지 확인.
- **10:00 본 응시 시작**, 별도 시작 공지 없음. **14:00 전체 종료**, 늦게 입장해도 연장 없음. 개별 일정 변경·일요일 응시 불가.
- 시작 전 화면 기준 작업 시간은 최대 180분이며 제출 후 확인 문제는 문제당 5분이다. 확인 문제와 준비·대기 시간을 포함해 전체 종료 시각 안에 마친다.
- 사전 체험은 감독 앱 연결·촬영 설정부터 확인하고, 실제 지시서 읽기·결과 저장과 재열기·원자료 대조를 먼저 확인한다. 남은 시간에 필요한 Skill·CLI를 점검한다. 이 순서는 패키지 운영 제안이며 공식 시간 배분 규정이 아니다.

## 이 패키지의 운영 선택

아래는 공식 조항을 확장한 금지 목록이 아니라, 이 패키지를 운용하는 방식이다.

- 검사 도구는 로컬 파일만 읽고 네트워크·외부 LLM·API 키·텔레메트리를 사용하지 않는다. 제공 Codex를 업데이트하거나 개인 모델·계정을 연결하고 보안 설정을 바꾸거나 차단을 우회하지 않는다.
- 메신저·브라우저·Computer Use 자동 조작과 자동 제출을 하지 않는다. 필요한 화면 확인과 메시지 발송·제출은 응시자가 직접 한다. 업무 판단 질문과 사용법 문의는 구분해 초안만 제공한다.
- 허용된 터미널에서 과제 자체의 실행·테스트와 필요한 로컬 CLI 검사를 수행한다. CLI를 사용할 수 없으면 수동 대조로 진행하고 미수행 범위를 남긴다.
- 내장 Browser 확인이 필요하면 응시자가 직접 처리한다. 이 문서는 브라우저 자동화 사용 권한을 부여하지 않는다.
- **AI 금지 후속 서술형 단계에 진입하면 Skill·CLI를 통한 AI 지원을 중단한다.** 해당 답안을 작성·첨삭하거나 우회 방법을 제공하지 않는다.

시험 전 공개 배포물에는 개인 프로필·실제 과제·시험 데이터·규정 PDF·작업 로그를 넣지 않는다. 시험 중 Git Push나 결과물 외부 전송을 하지 않는다. 사용하는 저장소는 2차 예선 결과 통지 전까지 공개로 유지한다. 규정 문의는 초안을 작성할 수 있으나 자동 발송하지 않는다. 호스트 인식과 설치는 허용된 사전 체험에서 확인하며 이 패키지가 시험 환경에서 인증됐다고 주장하지 않는다.
