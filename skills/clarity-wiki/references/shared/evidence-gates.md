# 공통: Evidence Gates (검증 근거와 인간 책임)

**언제**: 데이터 분석, 생성 문서의 사실 검증, AI Agent 자동화, 실제 운영 의사결정, 시험 과제.

## 관문 1: 착수 전

- 무엇을 사실이라고 주장해야 하는가? 그 주장을 지지하는 원자료는 무엇인가?
- 비교할 범위, 기준 시점, 버전, 중복/삭제/누락 처리 원칙을 정한다.
- 산출물별로 검증 방식과 '확인되지 않았을 때의 처리'를 정한다.

## 관문 2: 핵심 중간 결과

- AI가 만든 목록/숫자/결정/권장 조치 중 위험도 높은 것을 원자료와 대조한다.
- 반드시 직접 읽거나 실행한 증거만 `직접 확인`으로 표기한다.
- `AI가 확인`, `사람이 확인`, `미확인`을 구분한다.

## 관문 3: 제출, 발송, 변경 직전

- 원자료 대조, 예외 확인, 저장 상태, 파일 경로를 재검사한다.
- 기존 사용자 승인 범위를 확인한다. 그 범위 밖의 외부 조치만 필요한 결정을 확인하며, 허용된 작업에 반복 승인 단계를 만들지 않는다.
- 실패 시 복구 절차와 담당자를 기록한다.

## 짧은 증거 기록 예시

| 항목 | 근거 파일/위치 | 확인 방식 | 결과 | 확인 주체 |
|---|---|---|---|---|
| 불량률 계산 | `input.csv` + 집계 쿼리 | 원본 10건 표본 대조 | 일치 | 사람 직접 |
| 화면 버튼 동작 | 대상 화면 | 수동 클릭 및 반환 확인 | 정상 | 사람 직접 |
| 예외 로직 | `tests/test_edges.py` | pytest 4개 실행 | 통과 | 테스트 로그 |
| 원인 가설 | 설비 이벤트 시점 | 시간적 동시 발생만 확인 | 미확정 | AI 분석, 사람 검토 대기 |

**중요**: 위의 표는 예시이고 실제로 수행하지 않은 검증을 복사해 제출하면 안 된다. 검증할 시간이 없었다면 `미검증`과 영향 범위를 명시한다.
