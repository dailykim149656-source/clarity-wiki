# 질문을 규칙과 검증으로 바꾸는 가상 사례

아래 입력·답변·결과는 설명을 위해 만든 합성 예시다. 실제 업무 자료, 실행 결과, 테스트 통과 기록이 아니다. 필요한 사례만 참고하고 현재 과제의 지시·정책을 대신 적용하지 않는다.

## 일부만 답한 경우

- 상황: 매출 집계에서 취소 주문 제외와 환불 차감 시점을 물었고, 집계 담당자는 “취소 주문은 제외한다”만 확정했다.
- 처리: 취소 제외 규칙과 검증을 확정한다. 환불 시점은 미확정으로 남기고, 환불이 없는 입력의 집계는 계속한다. 담당자의 답을 “환불도 주문일 기준”으로 넓히지 않는다. 답변 원문·담당자·출처를 취소 제외 규칙에 연결하고, 남은 환불 질문은 다음 차례에 확인할 수 있다. 질문 수는 한 차례 최대 3개이며 전체 작업의 한도가 아니다.
- 검증 예: 정상 주문 100원과 취소 주문 40원의 예상 합계는 100원이다. 환불을 포함한 최종 합계는 시점 답변 전까지 미검증이다. 관찰값은 실제 실행 후 채운다.

## 적용 조건이 충돌하는 경우

- 상황: 월간 지표 과제는 “국내 주문만”, 최근 일반 안내는 “전체 주문”이라고 적혀 있다. 먼저 각 문서의 경로·절과 해당 조건을 정할 주체를 확인한다.
- 질문과 확정: “이번 월간 지표에도 전체 주문 안내가 적용됩니까?” 지표 범위를 결정할 담당자가 “이번 과제는 국내만”이라고 확정한 범위에 따라 처리한다. 다른 과제까지 국내만으로 바꾸지 않는다.
- 검증 예: 국내 100원·해외 50원 입력의 예상 합계는 100원이다. 가상 관찰값이 150원이라면 실패다. 충돌 해소 전에는 양쪽 조건에 공통인 입력 정리만 계속한다.

## 누락과 0이 다른 경우

- 상황: 재고 자료에 `A=0`, `B=값 없음`이 있다. 제공 자료에는 누락 처리 정책이 없다.
- 질문과 확정: “값 없음은 무엇을 뜻하며 집계·표시에 어떻게 반영해야 합니까?” 재고 담당자가 “미집계”라고 확정하면 `A=0`, `B=미집계`로 표시하고 B의 집계를 확인한다. 답변 전에는 누락을 0으로 채우지 않는다.
- 검증 예: 예상 표시는 A의 `0`, B의 `미집계`다. 가상 관찰값이 `A=0, B=0`이면 실패다. 누락 정책에 영향받지 않는 A의 확인은 계속한다.

## 합계는 같지만 키별 값이 뒤바뀐 경우

- 상황: 장비별 불량 건수의 정답 입력은 `장비 A=2`, `장비 B=5`다.
- 검증 예: 예상 합계는 7이고 키별 예상값은 A 2·B 5다. 가상 관찰값이 A 5·B 2라면 합계 7만 비교할 때 놓친다. 장비 키 집합과 각 키의 값을 함께 대조하면 실패를 확인할 수 있다.
- 처리: 장비와 값을 연결하는 부분을 확인하고 수정 후 같은 입력으로 다시 검증한다. 실제 재검증 전에는 통과로 기록하지 않는다.
