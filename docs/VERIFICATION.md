## 2026-10-31 합성 과제의 질문부터 제출 설명까지 실제 수행

기준 커밋 `6cb2f10`의 Skill로 실제 시험과 무관한 교육실 예약 배정 과제를 수행했습니다. 단일 사례의 실행 기록이며 기본 Codex와의 비교 실험은 아닙니다. 현재 지침을 수정해야 할 결함은 이 사례에서 재현되지 않았습니다.

### 과제와 역할

- 교육실 2개, 신청 8건. 정원·시간 겹침·중복 배정을 금지하고 CLI, 배정/미배정 CSV, JSON 집계, 실행 가능한 unittest, 제출 설명을 요구했습니다.
- 실행 에이전트는 지시서·스키마를 읽고 목표·상태/누락 priority·시간 경계를 첫 질문 3개로 추렸습니다.
- 운영 담당자 역할의 합성 S1은 priority 합계 우선·동률이면 건수 우선, active만 배정, 0도 유효하다고 답하고 두 조건을 보류했습니다. 실행 에이전트는 확정 범위만 반영하고 데이터 담당자에게 재질문 2개를 준비했습니다.
- 합성 S2는 누락 priority를 `missing_priority`로 제외하고 0으로 채우지 않으며, 종료와 다음 시작이 같은 구간은 연속 배정 가능하다고 확정했습니다. 유효한 priority와 status의 범위도 답했습니다.
- 답변은 사전에 작성한 모의 정책을 검토자가 중계했습니다. 실제 사람의 결정·외부 메시지·대회 시나리오 에이전트 접속은 아닙니다. 별도 QA 에이전트는 구현을 읽기 전에 지시·입력·확정 규칙으로 검증 사례를 만들었습니다.

### 실제 결과와 독립 확인

| 확인 | 실제 관측 |
|---|---|
| 제공 CSV의 실제 CLI 실행 | 입력 8건 = 배정 5건 + 미배정 3건, priority 합계 19 |
| 배정과 미배정의 행별 대조 | 배정 a/b/c/e/h, d는 미선택, f는 누락 priority, g는 취소. 원본 ID 누락·중복 없음 |

| 구현자가 작성·실행한 테스트 | unittest 13개 통과. 별도의 소형 전수탐색과 비교하는 고정 seed 사례 24개 포함 |

| 오류·경계 조건 | 정원·시간 겹침·연속 예약·0/누락·취소·빈 입력·중복 ID·잘못된 숫자/시간/상태·지원 최대 입력 검사 통과. 입력 오류 시 기존 결과 보존 확인 |

| 코드·설명·로그 대조 | 실제 함수 위치와 방법·대안·관측 결과가 일치. Python 3.10 미실행과 출력 전체의 비원자적 갱신 한계도 명시 |

검토자가 TMPDIR을 외장 디스크로 바꾼 추가 실행에서는 macOS AppleDouble 메타데이터 때문에 합성 과제 테스트의 일부 파일 목록 비교가 실패했습니다. 변경한 검토 조건을 기록하고, 문서대로 기본 임시 폴더 환경에서 새 복사본을 재실행해 13개 테스트 통과를 확인했습니다. 이 현상을 Skill의 결함으로 판정하지 않았습니다.

최종 검토자는 새 폴더에서 CLI 실행·13개 테스트·제출 목록 검사를 다시 수행했고, 원래 제출 파일의 해시가 바뀌지 않았음을 확인했습니다. 실제 실행 환경은 Python 3.14.6입니다. 실습 코드·입력·답변·로그·독립 검사·초기 제출 스냅샷은 작업 공간의 제작 검토 기록으로 보관하며 공개 배포에는 이 요약을 포함합니다.
